# 合成量化验收门禁 · 尝试登记账本(gate_ledger)

> 目的:所有实验/尝试按层级登记,**防止时间久了重复尝试已失败的方法**。
> 本文件是门禁工作(git 分支 `stage06-syn-gate`)的强制账本:开工先读,动手必记,收尾更新。

## 登记规范(强制)

1. **层级**:里程碑 `M#`(设计 §8)→ 任务 `M#.T#` → 尝试 `M#.T#.A#`(同一任务内递增)。
2. **每条尝试必含**:日期、一句话假设、方法(命令/脚本/参数)、结果(数字证据)、
   结论三选一:**✅ 采纳** / **❌ PROVEN-DEAD(禁止重试,除非有新证据并在此注记)**
   / **⚠️ 部分(遗留问题写明)**。
3. **失败实验代码**归 `rollback/`(不删除),账本留结论与复现路径。
4. **开工前检查单**(每次会话):
   - [ ] 读本账本(尤其 PROVEN-DEAD 清单)+ `STATUS.md`(现状与缺陷)+ `EXPERIMENT.md`(实验索引)
   - [ ] 涉及列线/结构语义时读 `EXPERIENCE.md`(废止路线与判读纪律)
   - [ ] 写码走 TDD、遇 bug 走 systematic-debugging、收尾走 verification-before-completion
   - [ ] 新目录先登记 `src/core/paths.py`;并行统一走 `src/core/batch.py`
5. 设计文档:`reports/设计_合成量化验收门禁.md`(验收标准唯一来源,改设计先改文档并留痕)。

  可大量复用开源,版式层无开源等价物需自研。方法:子代理联网调研 DocCreator/Augraphy/
  表格合成器/弯曲位移场/手写重组,笔记 `runs/table_reconstruct/调研_合成退化方案.md`。
  结果:DocCreator 不可作主体(C++/Qt GUI、LGPL、2023-11 停更、GT 仅文本级,仅墨迹退化/
  透印扩散/装订阴影三处算法可借鉴);Augraphy(MIT,活跃)可直接复用 BleedThrough/
  ShadowCast/LightingGradient/SubtleNoise 等参数化增强子;PubTabNet/SynthTabNet/
  TableBank 均无可复用"渲染+结构 GT"代码且图像全干净;无现成参数化弯曲位移场实现
  (Garai 2019 arXiv:1910.06621 作文献依据,自研正弦场+cv2.remap);中文手写重组无现成
  工具(v3 自建,不阻塞)。
  结论:**✅ 采纳**——复用决策:噪声/透印/灰度不均→Augraphy;模糊/倾斜→OpenCV 自写;
  弯曲/断线/黑边带/装饰框/平行双线/淡线→自研(版式层或 GT 同步要求)。
  **两条新约束进设计:①几何类增强器一律禁用于门禁路径(不回传坐标映射,GT 失同步;
  弯曲只能用自己的位移场,同时变换图像与 GT);②Augraphy 在 68.6MP 大图上性能无先例,
  M1 第一步先做性能验证。**
