# 当前技术决策

更新日期：2026-08-30

## 有效决策（用户明确或经验证）

1. 输入目录只读；实验写入 `runs/`；正式输出与历史错误输出分离；失败归档到 `rollback/`，不导入不运行。
2. `suspect` 保持原样不参与拟合；`direction==none` 的 noise 不参与拼接。
3. **问题定位**：第四阶段输出没问题（用户核验确认），**问题在第五阶段处理**。
4. **忠实数据源**：列线只能由第四阶段候选段构成，**禁止创造原图不存在的线条**——不得桥接远距段、不得延伸端点、不得分箱重采样重造线条。
5. **连续性优先于坐标**：相邻段坐标差距必然小；差距过大=拼错=断开。**禁止用固定 X/midx/单一全局斜率分组**（列线倾斜）。
6. **断口补齐三点要求**（用户）：斜率像 + 延伸能对齐 + 缺口能用同斜率补，缺一不可。
7. **真列线四特征**（用户）：连续且平直、具分隔作用、顶底相连、整体波动小。
8. **泛化优先 + 第一性原理**：合理阈值通用处理；不针对单张图特判；不靠"排除横线/限制列数"后处理掩盖问题；能写一行不写十行。
9. **验收**：先忠实画清楚列线；`n_columns` 不是本阶段硬门槛（那是列切分阶段的事）；必须含**视觉健全性**指标（折线/横线/跨列数）。
10. **新方向**：第五阶段按第一性原理重新设计，核心为**沿线追踪（line-following）**：从长段出发沿局部方向接续同线段直至贯穿全高。
11. 最终结构正确性由完整分辨率叠加图 + 用户肉眼核验决定。
12. **Track 归组实验定案（2026-08-30，用户布置）**：冻结线段（sha256 校验），只加归属 `Track=[seg_id,...]`；归组证据=原图墨迹沿线追踪（wedge 探墨+动量转向±25°+死推跳断口），跳距按「横向漂移≤12px」随倾角封顶，落点须命中未归属段顶端（横向≤12px<最小线距 37px 的一半、方向差≤10°）；像素路径不写回为线；三点要求由追踪结构化满足而非事后校验。产物 `runs/stage5_track_grouping/`；单测 `tests/test_track_group.py`。
13. **Track→列线判定（2026-08-30）**：同线合并护栏=接缝对齐≤20px 且两侧 res90≤15（挡曲线，实测挡住 T45 水位曲线）、同线双描重叠≤10px 才并；分隔线=跨表≥80% 且**表头带 y745-1035 有墨支撑**（条带边/曲线不进表头，像素实测）；双线外框=右侧 150px 内有 ≥60% 跨度平行伴线，不计列。1019 判定 **10 数据列**，judge 独立计数一致。脚本 `src/table/track_columns.py`。

## 已废止 / 不再采用

- 分箱中位重采样生成列线轨迹（产生折线伪影）。
- 用固定 X / midx / 单一全局漂移斜率做列线分组（列线倾斜，会错）。
- A2 段拼接实现（`BRIDGE_PERP_TOL=100` 吞并列、造横线/折线/跨列）——**不作为交付**，工作树中的改动勿当基线。
- 仅放宽 internal 规则或改显示颜色（无法修复真实结构）。
- 用 recall/precision 作为阶段5验收依据（不检测几何畸形）。
- 仅靠距离/角度/DBSCAN/普通图搜索做碎片归组（用户明确效果一般；track_group 实验以像素证据为主）。

## 阶段5 全局结构锚点（column_line_follow，2026-08-26 实现，后被 Track 归组实验补充）

- 模块：`src/table/column_line_follow.py`；产物 `runs/stage5_line_follow/`（待核验状态被 track_group 实验取代，见 activeContext）。
- 列身份来自水平段端点（表头行边界 + 全表端点直方图峰），不用固定 X/midx 聚类。
- 每个 run 只能分配给最近锚点走廊（min(30px, 0.4×最近邻距)，下限 12px），从构造上禁止串列。
- 桥接前必须过三点校验（`_valid_junction`）：对齐 d≤15、近垂直、斜率一致性（小缺口<20px 只查 |kb|≤0.5；大缺口 |kb|≤0.1，两端长 run 收紧到 0.05）。不合格断开不画桥。
- 桥接画线上限 = 500px（BRIDGE_DRAW_MAX_PX，依据：同线断口实测最大 457px）；超过只记录 gaps，不画线。
- 关键阈值：EP_BIN=6、EP_MIN_SEP=40、X_TOL_BASE=30、X_TOL_MIN=12、X_TOL_NEIGH_FRAC=0.4、BRIDGE_ALIGN_TOL=15。
