### Diagnosis（实际发生了什么 + 具体代码路径证据）

**问题 A：横线（|dx/dy|>2）与跨列（x 极差>150px）—— 桥接插值 + 端点闭合无几何约束**

- `_stitch_lines` L725-731：`gap > TRAJ_STEP` 时对相邻顶点做线性插值 `off = off0 + frac*(off1-off0)`。**只要两个顶点 x 差大、y gap 小，插值必然产出近水平线段**。复现：1035 x_ref=1001 `|dx/dy|=121.5`、x_ref=2640 `|dx/dy|=153.6`、x_ref=822 达 `118.0`——全部源自桥接插值。
- L752-758 端点闭合：把轨迹端点强行闭合到 `a_min/a_max`（该 lane 段 bbox 主轴范围），可能把无证据的尾段延伸 → 凭空线条。
- **根因**：桥接只检查 `gap ≤ BRIDGE_MAX_GAP`（主轴方向距离），**完全不检查垂直于主轴的偏移 |dx|**。x 相差 100px+ 的两顶点也照常线性插值 → 水平线 + 跨列。

**问题 B：折线（偏转>20°）—— lane 顶点直接折线连接，无斜率一致性约束**

- L715-723 逐段展开顶点：笔直段发 `(a0,off),(a1,off)` 两个顶点，相邻段之间直接首尾相接。当相邻段 off 差 50-100px、y gap 却 <20px（同簇 y 重叠合并后常见）→ 连接段方向突变 → 折线。复现：1035 x_ref=822 折线 156 点（最大 165°）、x_ref=1001 折线 184 点（最大 175°）。
- **根因**：`_stitch_lines` 允许"y 重叠合并"（A2 改动）后，**lane 内可以包含 off 相差 50-100px 的段**，但轨迹生成阶段仍把它们当同一连续线首尾直连 → 折线。

**问题 C：吞并列/跨列—— lane 归并容差过大且只用"最近 off/中位"单点判据**

- L679-690：`score = min(|off-extrap|, |off-med_off|)`，`tol = BRIDGE_PERP_TOL(100) + |k|*(gap+overlap)`。当 `BRIDGE_PERP_TOL=100`，**两条真实平行线（间距 34px）和不同列的段（off 差 50-100px）都会被并进同一 lane**。
- 复现：1035 x_ref=2640 x 极差 772px 跨约 3 列——一条 lane 吞并了多列段。
- **根因**：用**单点偏移**判同线，不是用**整体直线拟合**判同线。真正区分"同一渐倾线的多段 vs 真双线 vs 不同列"需要二维几何拟合（斜率+截距），单点容差在容差大时必然吞并、容差小时必然断线。

**问题 D：列内部短线（LANE_SPAN_MIN=0.25 过宽）**

- L241 `LANE_SPAN_MIN=0.25`：y 跨度 ≥25% 表高就保留。报告指出短碎片也被当列线 → 多余线条。

**核心矛盾的本质**：这不是"容差调大调小"的两难，而是**判据维度不足**：
- lane 归并用一维偏移容差 → 无法分辨"同线渐倾" vs "平行双线" vs "不同列"（需二维直线拟合）；
- 桥接只用主轴 gap → 无法阻止 x 大偏移的无效桥接（需垂直于主轴的 dx 约束）；
- 轨迹顶点直连无斜率约束 → 无法阻止折线（需段方向一致性约束）。

### Drift / contradiction check（漂移与矛盾）

- **任务假设「段拼接天然抗平行线、无需预删成员」在 A2 中过度实现**：为了修复 1015 的 y 重叠合并，A2 把 `BRIDGE_PERP_TOL` 从 50 调到 100 且允许 y 重叠合并，结果从"断裂"滑向"吞并"。**两个方向都偏离"忠实第四步段"的本意**——既不真（吞并列/造线），也不忠实（断线/凭空延伸）。
- 与 decisions.md"禁止局部折线/扭曲、不创造原图不存在的线条"直接冲突：当前实现系统性产出折线/横线/跨列。
- 报告第 5 条称"subagent 工具当前不可用"——本 oracle 会话可正常执行，该条仅反映当时会话状态，不构成对方向的否定。

### Recommendation（推荐方向，按优先级）

**方向 1（最高优先，治横线/跨列/凭空线）：桥接与端点闭合加几何健全性约束**
- 桥接前强制检查垂直偏移 `|dx| ≤ BRIDGE_MAX_DX`（建议 30~50px，可先量化校准）；不满足则不桥接（保留断口分段）。
- 移除/收紧端点闭合：只在有证据的段范围内闭合，禁止向无证据区延伸（或按邻近段斜率外推 ≤ 上限）。
- 效果：直接消灭 |dx/dy|>2 横线与 x 极差>150px 跨列。

**方向 2（治吞并列/断线的两难）：lane 归并改为"整体直线拟合残差"判据**
- 对每个 lane 维护其（主轴, 偏移）的直线拟合（斜率 k、截距 b、残差 std），新段并入条件改为：`|off_new - (k*y_new + b)| ≤ 拟合残差带（如 2σ + 固定容差）`，且新段自身斜率与该 lane 斜率差 ≤ 斜率容差。
- 这样"同一渐倾线多段"（拟合一致）并入，"平行双线"（截距差 > 残差带）分离，"不同列"（斜率/截距都不同）分离。
- 可复用 `_lane_slope` 扩展为带残差的全 lane 拟合。

**方向 3（治折线）：轨迹顶点生成加方向一致性约束**
- 相邻顶点连接前检查方向（|dx/dy|）是否在该 lane 拟合斜率的合理范围内；超限的顶点对断开（分段）而非强行直连。
- 或桥接改为"仅当两侧段线性外推可对齐（外推 x 差 ≤ 容差）才连"，否则保留断口。

**方向 4（验收加固）：加视觉健全性硬指标**
- 在验证流程加入：折线条数、横线条数、跨列线数、x 极差上限作为硬验收（如 1035 全 0 或 ≤ 小阈值），与 recall/precision 并列，防止再"指标达标、视觉失败"。
- `LANE_SPAN_MIN` 从 0.25 提高（如 0.6~0.8），过滤短碎片。

**方向 5（安全锚点）：保留 945642a 作为可回退基线**
- 若方向 1-4 短期内无法收敛，可先回退到 945642a（峰分离基线）作为交付状态，段拼接继续在实验分支迭代。**但 945642a 仍有分箱中位折线伪影**，仅作过渡，不视为最终方案。

优先级与取舍：方向 1+2 是治本（几何约束 + 拟合判据），方向 3 是折线的必要补充，方向 4 是验收保障，方向 5 是兜底。建议按 1→2→3→4 顺序推进，每步用 1015/1035 量化验证。
