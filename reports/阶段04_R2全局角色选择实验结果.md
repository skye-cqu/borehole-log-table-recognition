# 阶段04 R2：1015/1035 全局角色选择实验结果

## 一、结论

R2 已完成一次独立实验运行。它不再把每条轨迹单独按分数染成绿色，而是先计算跨轨迹关系，再进行数据派生阈值筛选和非交叉结构选择。

R2 的输出仍是实验结果，不是生产角色分配，也不代表真实列数。当前结果显示：

- 1015：从 32 条软轨迹中选出 14 条结构候选；
- 1035：从 33 条软轨迹中选出 13 条结构候选；
- 1035 已通过的最左侧轨迹 T0 被保留；
- 未选中的轨迹在“选中结构图”中不再显示为黄色待选线，而在“全部轨迹+拒绝层”中统一显示为灰色；
- 仍有部分选中轨迹暂时标记为 `uncertain`，说明 R2 尚未把所有 frame、主体边界和 separator 完全区分清楚。

本轮没有修改生产入口、原始候选标签或列数逻辑。

## 二、R2 相比 R1 实际增加的内容

### 1. 相对长度和持续性

加入：

- 轨迹跨度 / 图像高度；
- 归一化 y 分层覆盖率；
- 八个归一化高度带的占用情况；
- 上部到主体的延续代理分数。

长度不再是固定像素阈值，也没有把长轨迹直接判为列线。

### 2. 跨轨迹左右顺序

在共同 y 分层中比较轨迹 x 位置，统计：

- 顺序变化；
- 交叉事件；
- 归一化左右排名；
- 轨迹间的共同覆盖范围。

存在交叉或突然跳转的轨迹组合会受到惩罚。

### 3. 相邻间距和结构族

计算相邻轨迹间距的中位数和变异程度，并统计每条轨迹与其他长轨迹的无交叉兼容邻居数。兼容邻居数被转成数据派生的结构族分数，用于抑制孤立的水纹或内部曲线。

### 4. 横向交点支持

对二值图执行水平形态学开运算，结构元素长度取上一阶段数据派生的 x 尺度的 1.5 倍。随后统计轨迹与横向结构的交点支持和上下端支持。

这不是 OCR，也没有把所有横向黑像素都当成表格横线。

### 5. 两级角色判断

R2 先判断轨迹是否进入一个稳定的全局纵向结构集合，再在集合内给出实验性角色：

```text
frame / table_boundary / separator / uncertain
```

没有进入集合的轨迹标记为：

```text
rejected_by_global_structure
```

这个标签只表示“没有被本次全局结构选中”，不等价于已经证明它一定是水纹、文字或内部线。

| interference | 0.27145 |
| R2 实验角色 | frame |

T0 的 `frame` 是 R2 的实验性角色，不应被解释成已经完成了生产角色确认。它能够被保留，主要因为：

- 覆盖高度很大；
- 上部—主体连续性高；
- 左右顺序稳定；
- 位于当前结构集合的外缘；
- 没有发生轨迹交叉。

上一轮出现的局部“列→岩层→列”风险没有导致 T0 被删除或拆断。

## 六、R2 中途发现并修正的回归

第一版上部—主体覆盖计算错误地把该分数近似固定在 0.5。修正后，统一结构阈值曾短暂排除 1035 T0，原因是 T0 与相邻结构的间距分数较低，而不是像素支持或连续性变差。

该结果被视为实验回归，未交付。随后加入了数据派生的 frame/boundary 保留通道：只有同时满足较高相对长度、结构族支持和 frame/boundary P75 分数的轨迹才可绕过统一阈值。重跑后 T0 恢复进入选中结构。

## 九、当前是否建议进入生产角色分配

不建议现在进入生产角色分配。

R2 已经完成了从“独立轨迹高分”到“全局结构候选”的关键推进，并且保留了 1035 T0，但仍存在两个未完成点：

1. `frame` 与 `table_boundary` 仍是实验性启发式角色；
2. 被拒绝轨迹目前只能证明“不属于本次选中结构”，还不能逐条证明是水纹、文字或内部岩层线。

下一步应由用户查看两张完整分辨率的 `01_r2_selected_roles_full.png`。如果选中层中的主要绿色线均贴合真实列线，下一步再做小范围的角色校正；如果仍有内部线混入，应优先分析对应轨迹 ID 的横线端接和表头—主体关系，不应直接再调总阈值。
