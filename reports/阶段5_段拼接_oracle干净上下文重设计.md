6. 贯穿全高的参考高度**不能依赖全宽横线**：1015/1027 各自只有 1 条全宽 horizontal+high（仅底线 y18429 / y13884），顶线未被第四阶段检出；1035 才检到顶线(y746)。→ 表格垂直区间必须由**纵向链本身**定义（最大 span 链：1015 y[725,18383]、1027 y[729,13946]、1035 y[484,20661]）。

**主要问题**：旧 `column_fit.py` 把"聚类（mean-shift + x_ref）→ 去污染 → 拟合"当主机制，段拼接只是补丁；而聚类/去污染/裁剪（`_clip_jump`、`_members_outband_remove` 等）恰恰会误删真实段（memory-bank 已记录 outband 误删 1035 左 frame 22 段），且大容差把平行线并成一条线。这正是"断线问题的本质是漏掉了第四阶段已有的段"。

## Recommendation（核心：清晰正确的算法设计）

### 设计总则
- **列线 = 一组偏移连续的 vertical+high 段（逻辑同线）+ 忠实绘制这些段的自身点**。不做任何分箱重采样、不做远距插值。轨迹只含：(a) 各成员段自己的 points；(b) 仅在**小断口（≤BRIDGE_DRAW_MAX≈200px）**处做短桥接，使画面"清清楚楚"；(c) 绝不跨越真实大断口连线、绝不延伸端点。
- **分组与绘制分离**：逻辑归组用大断口上限（GAP_MAX）以保住贯穿全高判据；绘制用小断口上限，确保"画出的每根线都是原图有的"。

### Step 0 预处理
- 输入 = `direction==vertical && label==high` 的段；`suspect`、`none`、非 vertical 一律不参与（满足 AGENTS.md 约束）。
- 每段记录 `(y0, y1, x_off=midx, slope=dx/dy, points)`。

### Step 1 局部偏移连续性链式拼接（line-following，逐段生长 run）
- 按 `y0` 升序处理每段，尝试挂到**偏移最接近且通过判据**的活动 run：
  - 对该 run，取末段 `(y_last, x_last)` 与 run 的局部斜率 k（最近若干段的拟合/中位，初始 0）；
  - **漂移外推**：`x_extrap = x_last + k·max(y0 − y_last, 0)`（y 重叠时不外推）；
  - **连续性判据（核心）**：`|x_off − x_extrap| ≤ TOL_PERP`（建议 **25px**，安全区间 20–30；必须 < 最小列距 37.9px，且 > 同线段间真实偏移差 p90≈8.5）**且** `y0 − y_last ≤ GAP_MAX`（建议 **8000px**，覆盖已观测 7626 断口）。
  - 多 run 竞争时取偏移差最小者；冲突时较近者胜，败者所在 run 在此断开（保守）。
- **判据要点（对题目 Q1b/Q1c 的回答）**：
  - 大 y 断口 + 偏移一致 → 同一线（允许归组，不绘制桥接）；
  - 小 y 断口 + 偏移超差 → 不同线（断开，即使靠得近）；
  - 平行线因偏移差 ≥ 列距（34–38px）> TOL_PERP 天然分离，不会并错。
- **明确抛弃** `_stitch_lines` 的"y 重叠也并入"规则（详见下方 Q2）。

### Step 2 链级共线/垂直校验（验证，不是补丁）
- 对每个 run 用成员 `(midy, midx)` 最小二乘拟合斜率 k，做漂移校正：`x_ref = midx − k·(midy − ref_y)`，要求成员 x_ref 分布极差 ≤ TOL_PERP（即整链共线、无平行碎片混入）。若失败，按 Step 1 判据在该处拆链并重试归属。
- 近垂直校验：段级 `|dx/dy| ≤ SLOPE_MAX≈0.15`；链级 `|k| ≤ DRIFT_MAX≈0.012`（≈0.7°，覆盖观测 0.2–0.5°，排除 1027 的 45° 离群段）。

### Step 3 合并被劈开的同线链（split repair，保守）
- 两个 run 满足以下全部条件才合并：漂移校正后中位 x 差 ≤ TOL_PERP；y 区间相邻（断口 ≤ GAP_MAX）或重叠；合并后成员集**通过 Step 2 共线校验**。此步修掉 1015 xmed 290.7/292.4 这类同一根线被劈成两条的问题；1035 的 2875/2909（偏移差 34 > TOL）不会误合并。

### Step 4 贯穿全高 + 上下边相连过滤（对题目 Q1d/Q1e 的回答）
- **表格垂直区间（数据自洽定义，不依赖横线）**：取最大 span 的 run（或 top-5 run 的并集）的 `[table_top, table_bottom]`。1015 ≈ y[725,18383]、1027 ≈ y[729,13946]、1035 ≈ y[484,20661]。
- 候选列为真列线需同时满足：
  1. **span（min→max y）≥ SPAN_RATIO≈0.85 × 表高**（"贯穿全高"，断口计入 span：右框 1015 span 94% 仍过）；
  2. **union 覆盖（小间隙合并，间隙≤COVERAGE_GAP≈5px）≥ COVERAGE_RATIO≈0.55 × 表高**（"中途太短不算真列"：只有顶端+底端两小段的噪声线覆盖率极低，被拒）；
  3. **近似相连**：`y_min ≤ table_top + TOL_EDGE` 且 `y_max ≥ table_bottom − TOL_EDGE`，TOL_EDGE≈8% 表高（容 1015 右框顶部距表顶 1058px≈6% 的真实断头）；
  4. 垂直校验通过（Step 2）。
- 这些全部是**可量化、通用**的判据，不需要"排除横线/限制列数"的后处理；横线从不参与纵向拼接。

### Step 5 忠实绘制与输出
- 对每条真列线：按 y 升序串联成员 points（2 点段保留直度）；小断口 ≤ BRIDGE_DRAW_MAX≈200px 处线性短桥接；端点闭合到成员 bbox 主轴范围（不延伸）。跨大断口保持断开（忠实缺段）。
- 输出每条线的 `{id, trajectory, member_ids, span, coverage, slope_k, y_top, y_bottom, x_ref_at_mid}`。
- **不变量**：属于已验证线的任何成员段都不被丢弃；输出像素 ⊆ 成员段并集 ⊕ 小桥接容差——用栅格化断言校验"没有画出原图没有的线"。

### 对 Q2：`_stitch_lines` / `_stitch_segments` 的取舍判定
**保留：**
- "每段贡献自身点、保留每段直度、轨迹=成员点按主轴排序"的段拼接哲学（忠实第四阶段段）；
- 斜率外推补偿（`extrap = last_off + k·gap`）——大断口下同线判定的关键；
- 竞争性最近偏移匹配的思想；不延伸端点的原则。

**必须抛弃：**
- `BRIDGE_PERP_TOL=100`（及 decisions 的 50）：会并错 1035 的 34px 平行双线 → 改为 `TOL_PERP≈25`（< 最小列距 38）；
- "y 重叠也并入同 lane、偏移差放宽"的规则：会把 1015 col7 795/837 平行碎片并成一条 → 只允许偏移差 ≤ TOL_PERP 的并入；

- `_stitch_segments`"只保留最长一条轨迹"：每条真列线独立输出；
- 整个 mean-shift 聚类 + 去污染配套（`_split_cluster_peaks`/`_members_outband_remove`/`_members_span_filter`/`_clip_jump`/`_column_bandwidth`）与用于轨迹几何的 RANSAC：被链式拼接 + 全高过滤替代；`_global_slope`（长竖线斜率中位）可保留作为 k 的初始估计/DRIFT_MAX 参考。
