## 1. 背景与动机

项目从扫描钻孔柱状图恢复表格结构(行/列/单元格/坐标),最终输出结构化长表。
当前验收方式 = judge(视觉 LLM)逐轮核验 + 用户全分辨率肉眼终审(原则10)。
这套流程的两个反复出现的代价:

1. **回归发现太晚**:1035 切口 563.1 被改到 624(错 61px),judge 没看出、两次目读也没看出,
   最后靠翻 09-05 落账备份实锤——若与冻结真值逐线 diff,一行判死刑。
2. **judge 误读反复消耗轮次**:"13.76→13.7"、"零覆盖"等误报均靠人工像素核查才消解。

类比:寻路问题可用"目标时间"做验收,因为目标和尺子公认现成。本项目的尺子是
"原图真实印刷的表格结构",客观存在但锁在扫描图里。**缺的不是指标,是标准答案(GT)。**

## 2. 目标与非目标

**目标**
- 日常开发轮次**零人工**的量化回归门禁:每轮改动自动跑分,当场抓回归。
- 完全量化:每个像素有完美标签,指标 = 输出 vs GT 的确定性计算。
- 防"对 30 张固定图过拟合":可在任意多退化种子上回归。

**非目标**
- 不替代终版交付验收(将来同一基建扩到真实全量即可)。
- v1/v2 不覆盖逐格文本识别;内容层为 v3(§5.5),终态目标 =
  **结构可验证 100% + 内容可核查 100%**。

## 5. 组件设计

### 5.1 合成器(src/synth/)

**一句话**:程序画一张"理想钻孔柱状图",再按实测参数弄脏成假扫描件;
因为是程序画的,每条线真位置、每个格子的真边界天生精确已知 = GT,零人工标注。

**版式模型(全部从真图实测推导,不凭空捏造)**
- 列结构:标准版式列宽序列(左框/煤层sliver/深度/层厚/采长/倾角/真厚/柱状带/岩性/水文/右框,
  定稿阶段已拟合确认:60/65/125/80×4/200/1320/85?/545 量级);
- 行结构与 rowspan 模式:从 30 张定稿 JSON + 行线产物统计(行高分布、地质时代大格跨度、表头结构);
- 变体:v1 覆盖实测存在的 2~3 种(1023 窄柱状、缺柱状|岩性线、1032 左裁切)。

**v1 线系全要素**:列线、行线、上下框、侧线、装饰框、装订黑边带、平行双线、
淡线(灰度 172~196,真图实测带内)、断线(随机缺口)。

**v2 内容要素(紧随 v1)**:贴线文字(数字/表头)、柱状花纹、煤层黑条、水文锯齿曲线。
来源:真实裁片移植(保真实感)与字体渲染(可控)并行。

**几何退化(v1)**:纸张弯曲位移场、整体倾斜、模糊、噪声、透印、灰度不均。
**参数来源**:只读脚本对 30 张真图实测(曲率幅度、线宽分布、噪声谱、断线频率/长度),
合成器从实测分布采样——延续"参数要有实测推导链"原则。

**GT 产物(每张合成图自动附带)**
- 矢量折线(扫描系/矫正系每系精确——位移场是自施加的,这是合成路线独有红利);
- 单元格网格(含 rowspan 归属);
- 理想中间产物:理想二值图、理想骨架、候选段→真线归属表;
- N/A 标记段(故意施加的墨迹漫散等)。

**可复现**:每张图由 seed 唯一决定;run_batch 并行,批量 100~500 种子/轮。

### 5.2 判分器(src/verify/score_vs_gt.py)与记分卡

**双模式**
- 端到端:合成扫描图跑阶段 1→6j 全链(新增串联胶水,复用 run_batch);
- 隔离:理想骨架/候选段加扰动后直喂阶段 4→6j,屏蔽上游干扰——
  即 stage06 聚簇新旧方案对比所需形态(同一批合成候选段喂两套实现,比归组准确率)。

**v1 记分范围:列线 + 侧线 + 上下框,三层判分**

| 层 | 内容 | 判定 |
| --- | --- | --- |
| 结构层 | GT 每条线沿采样点核对覆盖率;无中生有线;线数匹配 | 0 容忍 |
| 几何层 | 匹配线逐采样点偏差分布 p50/p95/max | 阈值首轮试点实测推导后冻结 |
| 完整性层 | 画布/删除掩膜对合成真值逐像素核对("账外删除=0"合成版) | 0 容忍 |
| N/A 类 | GT 显式标记的模糊段 | 单列统计,不计 fail |

**输出**:每种子 pass/fail + 汇总通过率;fail 附违规明细 + 自动生成可疑点放大裁片
(沿用大图验收三件套:全分辨率+半分辨率+可疑点放大,单 judge/人工逐张可判);
记分卡 JSON+Markdown 进每轮汇报。

**阈值冻结机制**:首轮试点运行 → 实测分布 → 定阈值 → 冻结进配置;改阈值必须留推导链。

### 5.3 真实锚点(零新增人工)

- 30 张已核验定稿 JSON/闭合外框作为**固定回归基线**;
- 已知遗留登记 expected-fail:1035 右边界混轨、1042 左边界混轨+煤层|深度缺线、
  1020 缺柱状|岩性、1032 左裁切、36 处墨迹真断端差、4 切口贴线 p95 5.2~5.5px;
- 语义:基线记录**当前状态为下限**,算法改动产生**任何新增偏离**即门禁 fail;
- 补充(方案三残余,后续可选):1035 等疑难图可注入已知缺陷出题(mutation)。

### 5.4 保真度校准(防"门禁变摆设")

合成器的验收标准不是"像不像",而是**现行管线已知 bug 必须能在合成图上复现**:

| 失败模式(历史实锤) | 依赖要素 | 归属 |
| --- | --- | --- |
| 装饰框/黑边带被误吸成列线/侧线(52/60 侧线污染、1035 右混轨) | 装饰框、黑边带 | v1 |
| 淡规则线被二值化切断(INK_THR=150 切碎 1015 岩性行线) | 淡线 | v1 |
| 天窗直线桥接(30 张累计 366 处) | 断线 | v1 |
| 恒定 x 假竖线(sem 兜底造线,坐标系错配) | 几何退化+断线 | v1 |
| snap_to_ink 被柱状花纹/煤层黑条骗 | 花纹/黑条 | v2 |
| 贴线文字勾走墨迹跟踪(1035 数字区) | 贴线文字 | v2 |
| 表头横笔画误判行线 | 表头文字 | v2 |
| 底框沿水文锯齿走出 600px 假外延 | 水文曲线 | v2 |

复现不了 = 合成器太干净,打回调参。另有渲染自检单测,双向强制画账一致:
正向每条 GT 线有墨(逐线采样点灰度核对),反向每处墨属于 GT 元素(暗像素均落在线/
面块缓冲带内)——反向缺位时,渲染器自身 bug 会被判分器冤枉给管线。

### 5.5 内容层路线(v3)与"可核查 100%"验收协议

**事实与边界**:需识别内容(深度/层厚/采长/倾角/真厚数字、岩性描述中文)**全部手写**
(用户确认)。手写内容的"机器盲识别 100%"原则不成立;能承诺的是**可核查 100%**:
每个格子要么多引擎高置信一致自动通过,要么人审确认——"100%" = **零未核查格**。

**数字格确定性互证(候选,须按原则 9 先只读验证关系在数据中成立)**:
层厚 = 相邻深度差、真厚 ↔ 层厚×cos(倾角) 等。若成立,数字格获得"校验和"级验证,
配合多引擎一致,人审占比可压到很低;不成立则如实回退到纯多引擎协议。

**中文描述格**:手写识别多引擎交叉(候选:PaddleOCR 手写模型、VLM 类、项目内 Agnes)
+ 岩性领域词表约束(泥岩/砂岩/煤层等近封闭词汇域)。

**人审最小化**:按置信度排序,只送低置信/引擎分歧格;审校界面 = 原格裁片并排 +
候选读数,不改即确认。人审占比不做先验承诺,首批真实图实测后定口径(原则 9)。

**素材反哺**:人审确认的读数沉淀为**手写素材库**——供 v3 合成器做"真实手写重组"
(裁真实手写字/词重组进合成格,标签精确已知)。人审工作量同时产出交付物与合成器素材。

**v3 记分**:手写重组合成图上的字符级/格级准确率(合成 GT 判分);真实图按验收协议
产出置信度分级清单,零未核查格即为达标。

## 6. 门禁自身的验收标准(meta,三条硬标准)

1. **已知 bug 复现**:上表 v1 范围内 4 类失败模式全部在合成图上复现且被门禁抓到;
2. **锚点一致性**:门禁对 30 张真图的判定与用户历史核验结论一致(零新增偏离);
3. **误报率校准**:首个里程碑对照用户核验结果校准阈值/误报率,此后阈值冻结。

达成判定:
1. 合成器:给任意编号即出图;同一编号重跑两次文件完全一致;程序自动数值核对图像墨迹
   与标准答案一一对应(每条线有墨、每处墨有线);批量生成零失败;单张≤60秒。
2. 自动判分:对列线、侧线、上下框逐项打分——标准答案的线100%被找到;答案之外没有多余的
   线;画面没有误删的内容;线位置上95%的采样点偏差≤3像素(初始值;改动必须给出实测依据)。
3. 门禁反放水:构造4种"必错图"(装饰框被误认成表格线/淡线被切断/断口被直线桥接/凭空
   出现的恒定x假线),现行管线在这4种图上必须被自动判分抓出,并报出抓错的具体指标和
   数值(4/4)。
4. 真实图锚点:每次改动管线,30张用户已核验的定稿图上不得出现任何新偏离;"已知例外
   清单"(如1035右边界)冻结为文件,增删必须经用户确认。
5. 聚簇实战:新旧两套列线聚簇方案,在同一批≥100张合成图的候选段上各出一份自动判分,
   结果提交用户裁决。
6. 内容层打底:先用真图验证"层厚=相邻深度差"这类互证关系是否成立(要有实测数字);并对
   ≥1张真实图跑出置信度分级清单,人工审核占比有实测数字。
